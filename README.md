# 🛒 Python E-Commerce Platform

## 📌 About Project

This is a console-based E-Commerce Platform developed using Python. It allows users to register, login, view products, manage shopping carts, and perform shopping operations. Admin users can manage products and stock.

## 🚀 Technologies Used

- Python
- Object-Oriented Programming (OOP)
- File Handling

## ✨ Features

### 👨‍💼 Admin Features
- Add Products
- Delete Products
- Update Products
- Search Products
- View All Products
- Manage Product Quantity

### 👤 User Features
- User Registration
- User Login
- View Products
- Search Products
- Add Products to Cart
- Decrease Cart Quantity
- View Shopping Cart
- Calculate Total Amount

## ⚙️ How to Run

**Step 1:** Install Python 3.

**Step 2:** Clone the repository.

```bash
git clone https://github.com/BalaAnkiReddy5103/Python-Mini-Ecommerce-Platform.git
```

**Step 3:** Open the project folder.

```bash
cd Python-Mini-Ecommerce-Platform
```

**Step 4:** Run the application.

```bash
python ecommerce.py
```
